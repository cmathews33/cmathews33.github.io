CollectorFunction — Five Daily Phases Scheduled

Phase When (ET) What it does
accumulate Hourly, all week Fetch Reddit hot feeds, map posts to tickers, merge into today's per-ticker tally (deduped by post URL)
select 8:00am daily Read the 24h window from 8am yesterday to 8am today, rank tickers by distinct-post count, freeze top 20 with post links as the day's displayed list
open 9:30am, weekdays Fetch live prices for the frozen 20 and record each ticker's start-of-day price (sodPrice)
price Every 15 min, 10am–4pm, weekdays Refresh live prices for the frozen list. Reddit data is not refreshed — the list is fixed for the day
close 4:00pm, weekdays Write one daily trend record per ticker (SOD price, EOD price, % change, post count, post links)

ApiFunction HTTP

  • Reads from DynamoDB and returns JSON
  • Does no data fetching itself
  • Zero cost when idle — only runs on request

Why the list is frozen daily

Reddit posts are accumulated continuously and the top 20 by distinct-post count are frozen once at 8am ET, based on the preceding 24-hour window (8am yesterday → 8am today). For example, the list shown on June 4th reflects posts from 8am June 3rd through 8am June 4th — anchored just before US market open. This makes day-over-day trends legible and the displayed list doesn't churn every 15 minutes.

/api/stocks

{ "stocks": [...], "refreshedAt": "2026-06-08T20:15:00+00:00" }

Each stock: { ticker, name, price, priceChange, percentChange,
              mentionScore, totalComments, source, postTimestamp,
              posts, sodPrice }
refreshedAt
Timestamp of the last successful price collector run. If it is hours old during market hours, the collector is likely failing or throttled.
price / priceChange / percentChange
Regular market session price from the last price run. Uses regular_market_price from yfinance — extended-hours prices are excluded to match Yahoo Finance's official day change.
sodPrice
Start-of-day price captured at market open (9:30am ET). null before the open phase runs.
mentionScore
Plain count of distinct Reddit posts mentioning this ticker, accumulated through the day the list was selected. No weighting — one post = one point. Not a comment count — RSS does not expose actual comment counts.
posts
Up to 15 links to the actual Reddit discussions: { title, url, subreddit, postedAt }. Shown as expandable links in the stock table.
postTimestamp
Time of the most recent Reddit post mentioning this ticker. A Reddit signal, not a price freshness indicator — use refreshedAt for that.

/api/historical?period=month

Valid period values: day (1d) • week (7d) • month (30d) • year (365d). The old 1mo / 6mo / 1yr values return 400.

periodPostCount
Sum of postCount across all days in the query window for this ticker. Backfilled rows count as 0. This is what ranks tickers in the historical tab.
periodPriceChange
Percent change from the first sodPrice to the last eodPrice in the window. Computed by the API using proper SOD/EOD anchors — the frontend reads this directly and does not recompute it.
sodPrice / eodPrice
Start- and end-of-day price for each daily record. Backfilled rows have sodPrice == eodPrice == close (yfinance daily close).
postCount
Distinct-post mentions of this ticker accumulated throughout that specific day. Real from deploy date forward; 0 for backfilled rows.
source
"backfill-{period}" for seeded rows (price-only). Subreddit name for live-collected rows.

Which tickers appear in each period tab?

The multi-ticker response reads the KNOWN_TICKERS index (every ticker ever in a close record or backfill), queries each ticker's daily records within the window, filters to those with at least one record, and ranks by periodPostCount descending, capped at 50. Each period tab therefore shows the tickers that were actually Reddit-trending in that window, not just today's live 20.

What the Data Is Not

  • Not real-time prices — intraday prices are snapshots from the last price run (every 15 min during market hours); the daily record is anchored to the open and close captures
  • Not a day-trading signal — the purpose is to compile Reddit discussion + daily price movement into one place over time, not to surface intraday opportunities
  • Post history only exists from deploy date forward — backfilled rows carry real yfinance prices but postCount=0, since Reddit post history for past dates was not tracked
  • List is frozen daily, not live — the 20 stocks shown today were the top Reddit-mentioned tickers in the 24h window ending at 8am today; intraday price refreshes apply to that fixed list

Post Count In Depth

How posts are counted

Through the day, each accumulate run scans the current Reddit hot posts and records, per ticker, the distinct posts that mention it ($TICKER or a bare uppercase token, filtered against a blocklist). Dedup is by post URL, so the same post seen across multiple runs counts once. At midnight the select run ranks tickers by this accumulated distinct-post count and freezes the top 20. The close run carries the day's final count into the daily trend record as postCount.

No weighting

A ticker mentioned in 5 posts scores 5, whether the posts used $TICKER or a bare uppercase token. The old $TICKER = 2 / bare-caps = 1 weighting was removed to make the count directly interpretable.

Where post counts appear

mentionScore — Live tab
Posts accumulated for this ticker on the day it was selected into the frozen list.
postCount — Historical points
Posts for this ticker on that specific calendar day.
periodPostCount — Historical period summary
Sum of postCount across all days in the query window. This is what ranks tickers in the period tabs.
